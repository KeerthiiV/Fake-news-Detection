#Fake News Detection

This project is a Machine is a Machine Learning based Fake News Detectionsystem taht classifies news article as **Real** or **Fake** using Natural Language Processing(NLP) techniques.

## Project Overview
Fake news has become a major problem in digital media.
This project aims to identify fake news article using supervised machine learning algorithms trained on lalbeled news data.

## Technologies used
- Python
- Scikit-learn
- Pandas
- Numpy
- NLP
- Jupyter Notebook
- HTML (basic frontend)
